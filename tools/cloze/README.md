# 克漏字原稿格式（tools/cloze/D183.txt …）

每一回一個檔案，檔名是回數（D183.txt）。每篇文章：

```
## 中文標題
英文文章，挖空寫成 [[正確答案|誘答1|誘答2|誘答3]]，每篇剛好 5 格，全文不超過 250 字。
> 1 第 1 格的中文詳解（為什麼是這個答案、其他選項為什麼不行）
> 2 …
> 3 …
> 4 …
> 5 …
+ 專有名詞或超出範圍的字 = 中文解釋（每篇最多 5 個，可以沒有）
= 全文中文翻譯
```

- 正確答案一律寫在第一個，網站會自動打亂選項順序（固定亂數，不會每次變）。
- 答案以這一回和之前各回（D183 往下到這一回）的單字為主；四個選項詞性相同、只有一個放進文章才通順。
- 寫完執行 `python3 tools/build_cloze.py` 產生 docs/cloze/ 與答案檔，再執行 `python3 tools/check_bank.py` 檢查。
- 已發布的題目，題號（「回-篇-格」）固定不變；修改內容不會改題號。

## 主題建議（老師 2026-11-17 指定）
- 每回 30 篇裡，請盡量包含：
  - 韓團／歌手主題（追星、演唱會、練舞、選秀、偶像簽名會…）。團名、歌手名用虛構的；提到真實團體時只寫粉絲的經驗，不替真實藝人編台詞或情節。
  - 笑話、趣味主題（冷笑話、誤會、腦筋急轉彎式結尾、搞笑烏龍）。
- 如果之後這裡加入班上同學的名字清單，主角可以改用清單裡的名字。
